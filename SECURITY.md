# Security

This template contains no services, credentials or network code beyond git
push and pull to a remote you control. Its security model is the one stated
in `GOVERNANCE.md`: repository membership is clearance, and anything that
needs tighter handling stays out of the repository.

If you find a way the agent instructions or the sync script could cause data
to leave a business's repository unintentionally, or a privacy heuristic that
fails in a way worth fixing, open an issue describing the class of problem.
Do not include real content from any business in the report.
