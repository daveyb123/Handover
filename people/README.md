# people/

One folder per person, named by their slug (`alex`, `sam`). Three files each,
copied from `.template/`:

- `profile.md` — self-written via a short interview. Role, strengths, what they
  own, how they like work handed to them. Shared on purpose: everyone can read
  how everyone likes to work, so delegation gets phrased right.
- `tasks.md` — their commitments to the team. Delegation writes here.
- `inbox.md` — unprocessed captures from any source.

The agent creates a person's folder the first time they run the CLI in this
repo and runs the profile interview. Nobody edits these by hand.
